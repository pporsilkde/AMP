# ArenaMP X036 — Server Quest Dialogue Sync + пример Кая Косадеса

## Что добавлено

X036 подключает Server Quest Core X035 к обычному окну диалога ArenaMP.

- опубликованные server quest topics синхронизируются игроку сервером;
- в DialogueWindow они отображаются зелёным цветом;
- клиент не выполняет DIAL/INFO или награду локально;
- при клике клиент отправляет непрозрачный токен `@ArenaQuest:<questId>:<topicId>`;
- сервер проверяет NPC, ячейку, статус квеста, текущую стадию и requirements;
- сервер выбирает следующую стадию и только после проверки выдаёт rewards;
- ответ NPC возвращается скрытым служебным GUI-пакетом и вставляется прямо в историю обычного диалога;
- завершённый квест автоматически исчезает из списка зелёных тем.

Wire-format GUI packet не изменён, но сервер X036 следует использовать с клиентом X036: старый клиент не знает служебный GUI id `-35036`.

## Встроенный пример: «Выпивка для Кая»

Файл:

`server/data/custom/quests/arena_caius_drink.json`

Квест уже `published` и добавлен в `server/data/custom/quests/index.json`.

NPC:

- refId: `caius cosades`
- cell: `Balmora, Caius Cosades' House`

Зелёная тема:

`немного выпивки`

Предмет:

`potion_mazte_01` × 1

Награда:

- 75 gold;
- 40 XP (умножается на серверный `xp gain multiplier`, если XP reward не помечена `scaled=false`).

## Как пройти

1. Запустить X036 сервер и X036 клиент.
2. Зайти к Каю Косадесу в его дом в Балморе.
3. Открыть обычный диалог.
4. В списке тем должна появиться зелёная тема `немного выпивки`.
5. Нажать её. Кай попросит принести бутылку мацта. Квест перейдёт на stage 10.
6. Найти/получить `potion_mazte_01`.
7. Снова поговорить с Каем и нажать ту же зелёную тему.
8. Сервер проверит наличие бутылки. Если её нет — останется stage 10 и Кай повторит просьбу.
9. Если бутылка есть — сервер переведёт квест на stage 20, заберёт одну бутылку, выдаст 75 gold и 40 XP.
10. После завершения зелёная тема исчезнет.

Для повторного теста Moderator/Admin может выполнить:

`/quest reset arena_caius_drink`

После reset клиентский список тем синхронизируется заново.

## Как сделать похожий квест

Скопировать `arena_caius_drink.json`, изменить `id`, `name`, giver, topic и stages, добавить новый id в `index.json`, затем выполнить:

`/quest reload`

Либо собрать тот же квест через `/quest` редактор X035.

Ключевой шаблон двух стадий:

- stage 10: просьба, journal, `next: [20]`;
- stage 20: requirement `item`, reward `takeItem`, затем gold/xp, `complete: true`.

## Что ещё не входит в X036

X036 пока не вставляет server journal entries в ванильное окно Journal Morrowind. Состояние и записи уже хранятся сервером и доступны через `/quest journal`, но полноценное объединение с оригинальным Journal GUI — следующий этап.

Следующий слой логично посвятить choices/ветвлениям server dialogue и интеграции записей server quests в обычный Journal.
