ArenaMP CUMULATIVE — Modern Account Login + Language + Door Pursuit Fix

Base: AMP.zip (ArenaMP/TES3MP project used in this conversation)
Type: ChangedFilesOnly cumulative overlay

This archive includes the prior adapted ArenaMP cumulative work (NPC/dialogue/AI World V1-V4/Luxora-native effects) plus the following changes:

LOGIN / ACCOUNT UI
- Replaces sequential name + server password windows with one modern ArenaMP account card.
- Uses the original ArenaMW menu logo resource (textures/menu_arenamw.png).
- Name and password are entered together.
- RU / EN server-interface language selector is available on the same card.
- The selected language is applied to ArenaMP-owned UI immediately and reaches LocalPlayer language before PLAYER_BASEINFO is sent.
- Existing TES3MP password GUI protocol is preserved: the password collected by the card is automatically submitted when the server sends its normal PasswordDialog.
- If the server rejects the password, the same account card is shown again in retry mode; the account name is locked for the current connection.
- Ordinary in-game server TextInputDialog/PasswordDialog windows remain unchanged and unbranded.

NPC DOOR PURSUIT
- Fixes the MP-only regression that cancelled all delayed hostile NPC door transitions.
- Queue-time LocalActor authority validation is retained.
- Forward pursuit is no longer rejected after the origin cell unloads and TES3MP drops the old LocalActor authority record.
- ReturnHome still requires current authority at execution time.
- Existing follower-cell-change bypass is used only for forward pursuit/follower transfers, not ReturnHome.
- The visual 0.70–1.40 s delayed door transition remains enabled.

INSTALL
Copy the archive contents over the matching ArenaMP source tree, preserving directories, then build normally.
