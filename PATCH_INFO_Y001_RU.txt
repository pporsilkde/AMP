ArenaMP Y001 — cumulative patch over X057
==========================================

База:
  ArenaMP_X057_SOURCE_CLEAN_EN_RU(1).zip

Исправления Y001:

1. Launcher / вкладка Graphics -> Quality
   - Возвращено применение ручных настроек страницы графики при Play/закрытии.
   - Работают Water, Terrain Detail, PBR Quality, lighting, shadows,
     resolution/fullscreen/vsync/AA и ограничение FPS.
   - Сохранение сделано merge-safe: лаунчер определяет изменения относительно
     снимка, из которого были заполнены controls, затем перечитывает актуальный
     settings.cfg и накладывает только изменения страницы Graphics.
   - Поэтому более свежие настройки, записанные самой игрой, не перетираются
     старой копией settings.cfg из памяти Launcher.
   - Графика сохраняется на диск до PlayPage/XP save pass, поэтому последующее
     перечитывание settings.cfg больше не уничтожает графические изменения.

2. Новый HUD FPS counter
   - F3 НЕ изменён и остаётся hotkey HDR.
   - HUD counter отображает явную строку "FPS: N".
   - При первом запуске Y001 выполняется однократная миграция, включающая новый
     HUD counter даже для старого профиля с прежним show fps=false.
   - После миграции переключатель HUD -> Show FPS counter снова полностью
     управляется пользователем и сохраняется штатно.
   - Удалена устаревшая EN/RU подсказка, утверждавшая, что F3 показывает FPS.

Версия/совместимость:
  Source snapshot: ArenaMP Y001
  Network protocol: 806 (не менялся)

Установка:
  Распаковать содержимое архива поверх исходников X057 с заменой файлов,
  затем выполнить обычную сборку ArenaMP.

Проверка в этой среде:
  - XML openmw_hud.layout успешно разобран.
  - Сигнатуры GraphicsPage::saveSettings согласованы.
  - F3/HDR implementation source не изменён.
  - CMake дошёл до поиска системных зависимостей и остановился из-за отсутствия
    OpenGL/GLX development libraries в текущем Linux-контейнере; это ограничение
    среды проверки, а не диагностированная ошибка исходников Y001.
