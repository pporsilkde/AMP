# ArenaMP X050d — HUD / Player Menu chat state fix

База: X050c.

## Исправлено

1. `files/tes3mp/tes3mp-client-default.cfg` заменён на предоставленный пользователем вариант. X049-ключи больше не дублируются между `settings-default.cfg` и `tes3mp-client-default.cfg`: состояние Player Menu хранит дефолты только в `settings-default.cfg`.
2. HUD-чату возвращена геометрия X048: `x=1, y=25, w=260, h=400`.
3. `x/y/w/h` из секции `[Chat]` теперь используются как сохранённая геометрия только расширенного Player Menu. При `Y` панель разворачивается до сохранённых размеров (минимум 620x380), при выходе снова становится компактным HUD.
4. HUD использует прежний широкий шрифт `Russo`. В интерактивном чате история и поле ввода переключаются на `DejaVuLGCSansMono`, чтобы сохранить Unicode/emoji-ввод.
5. Для интерактивного чата добавлен отдельный `GM_ARENAMP_PlayerMenu`. Это штатно переводит OpenMW WindowManager в GUI mode: mouse-look/камера отпускаются, курсор становится видимым, MyGUI получает мышь. При закрытии режим удаляется.
6. `MW_Box` оставлен только рамкой. Основная подложка окна заменена на штатный `FullBlackBG` с alpha 0.92, поэтому область ввода/Player Menu имеет реальную тёмную заливку.
7. `MinSize` layout возвращён к `40 40`, иначе MyGUI сам не позволял сжать пассивный HUD обратно до ширины 260.

## Ожидаемое поведение

- В игре: компактный прозрачный HUD старого размера, Russo.
- Нажать Y: окно становится 620x420 (или сохранённого размера/позиции), появляется тёмный фон и рамка, камера перестаёт реагировать на движение мыши, появляется курсор, история переключается на DejaVu LGC.
- Перетащить окно и закрыть: координаты большого окна сохраняются; HUD возвращается к 260x400 и не наследует размер Player Menu.
- Повторно Y: большое окно открывается на сохранённой позиции.
- Esc / «В игру»: возвращает camera-look и скрывает курсор штатным WindowManager GUI-mode transition.

## Конфиги

`tes3mp-client-default.cfg` в X050d оставлен ровно в предоставленной пользователем структуре. X049 player-menu defaults (`send channel`, `send style`, `rp mode`, `stay after send`, `player menu tab`) находятся только в `files/settings-default.cfg`.
