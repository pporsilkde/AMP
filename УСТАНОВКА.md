# ArenaMP X048 — кумулятив, файлы целиком

Здесь лежат 17 файлов **полностью, а не патчем**. Структура каталогов внутри
архива совпадает с деревом AMP, поэтому установка сводится к одному действию:

```
скопировать содержимое архива (папки apps/ и server/)
поверх корня дерева AMP, с заменой
```

В Windows — просто перетащить `apps` и `server` в корень проекта и согласиться
на замену. В консоли:

```
cp -a apps server /путь/к/дереву/AMP/
```

Проверено: копирование этих файлов на чистое дерево из `AMP.zip` даёт результат,
побайтово совпадающий с эталонным деревом, на котором я работал (`diff -rq`
пустой).

## Переносы строк

В вашем дереве часть файлов лежит с CRLF, часть с LF — я сохранил ровно то, что
было в оригинале, побайтово:

```
CRLF : apps/openmw/mwmp/ObjectList.hpp
       apps/openmw/mwmp/processors/actor/ProcessorActorList.hpp
       apps/openmw/mwmp/processors/object/ProcessorContainer.hpp
       server/scripts/customScripts.lua
LF   : все остальные
```

Если будете открывать их редактором, который «чинит» переносы, — не давайте ему
этого делать, иначе получите огромный мусорный diff в git.

## После установки

В `server/scripts/config.lua` рекомендую выставить:

```lua
config.allowConsole = false
```

Скрипт владельца всё равно перекроет это значение на логине, но так консоль не
будет на долю секунды доступна всем между логином и `OnPlayerFinishLogin`.

Если хотите переназначить владельца с нуля — удалите
`server/data/world.json` (или очистите в нём ключ `arenampServerOwner` внутри
`customVariables`). Следующий зарегистрировавшийся аккаунт займёт слот.

## Порядок проверки

1. Соберите клиент и сервер.
2. Зарегистрируйте первый аккаунт → в логе сервера
   `[OwnerConsole] <имя> is the first registered account and is now the server owner`,
   консоль работает. Второй аккаунт — консоль не открывается. Команда `/owner`
   показывает текущего владельца.
3. Селлус Гравиус: зелёная тема «поручение канцелярии» → «Слушаю» → «Да,
   документы у меня». Должны прийти 50 золота, сообщение «Дневник обновлён» и
   **запись в обычном журнале по клавише J**.
4. Кай Косадес без бутылки: нажмите «Вот бутылка мацта» → придёт
   `Не выполнено условие — предмет "potion_mazte_01": нужно 1, у тебя 0`.
   Зацикливания быть не должно.
5. Купите мацт в таверне, повторите → квест завершится.
6. Отдельно проверьте консольный путь: `player->additem potion_mazte_01 1`, затем
   сразу «Вот бутылка мацта». Раньше это не работало вообще — сервер про предмет
   не знал. Теперь должно сработать за один клик, за счёт отложенного повтора.
7. Выйдите в экстерьер и побегайте между ячейками — рывок должен исчезнуть или
   заметно ослабнуть.
8. Откройте `/quest studio` — кнопка «Выход» должна быть на экране без растягивания
   окна.

## Чего я не проверил

**Ничего не скомпилировано.** Зависимостей OpenMW и сети в моём окружении нет.
Lua проверен только на баланс блоков и порядок объявлений, JSON — на
парсабельность. Настоящего интерпретатора Lua тоже не было.

Проверьте в первую очередь — эти сигнатуры MyGUI 3.2 я брал по памяти,
и если что-то не соберётся, скорее всего именно здесь:

- `MyGUI::Widget::castType<T>(bool)`
- `MyGUI::EnumeratorWidgetPtr` / `Widget::getEnumerator()`
- `MyGUI::FontManager::getByName()`

На стороне сервера — `player->guid` в `ItemFunctions::RequestInventory`
(`BasePlayer.hpp:188`, тип `RakNet::RakNetGUID`, совпадает с тем, что принимает
`BasePacket::RequestData`).

**Раскладка Quest Studio не входит в этот пак.** В `AMP.zip` нет каталога
`files/`, а ваш `ServerQuestEditor.cpp` уже требует виджеты `OverviewHint` и
`HelpText`, которых в layout из X043a нет — значит, у вас на диске более новая
версия, которую я не видел. Переписывать её вслепую значило бы сломать
`getWidget` и уронить студию при открытии. Автоподгон и шрифт сделаны в C++ и от
версии layout не зависят. Пришлите
`files/mygui/arenamp_serverquesteditor.layout` — сокращу количество кнопок и
сделаю постоянную нижнюю панель.

Полное описание каждого исправления — в `X048_README_RU.md`.
