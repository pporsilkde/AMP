# Отличия ArenaMP от TES3MP 0.8.1

ArenaMP наследует мультиплеерную основу TES3MP 0.8.1 и движок OpenMW 0.47.0, но не является взаимозаменяемым клиентом или сервером для обычного TES3MP.

## Главное о совместимости

Официальный TES3MP 0.8.1 использует protocol `10`. ArenaMP X057 использует собственный protocol `806`, расширенные структуры пакетов и дополнительные нативные Lua API. Общая строка версии `0.8.1` показывает происхождение кода, но не означает сетевую совместимость.

Клиент и сервер следует собирать из одной ревизии ArenaMP. Смешивание разных сборок не поддерживается, даже если обе показывают `0.8.1`.

## Основные отличия

| Область | TES3MP 0.8.1 | ArenaMP X057 |
|---|---|---|
| Сетевой протокол | Protocol 10 | Собственный protocol 806; нужна одинаковая сборка |
| Серверные скрипты | CoreScripts обычно выбираются и ставятся отдельно | Серверное ядро ArenaMP встроено в проект и релизный пакет |
| Локализация | В основном зависит от серверных скриптов | Встроенный EN/RU интерфейс и язык сообщений отдельно для каждого клиента |
| Чат | Окно чата TES3MP и команды скриптов | Меню игрока, RP/OOC-каналы, список игроков, цвета, emoji, безопасный UTF-8 |
| Группы | Отдельные скриптовые реализации | Постоянные группы, приглашения, лидер, UI, разделение XP |
| Friendly fire | Обычные allies и серверные скрипты | Нативные режимы disabled/enabled/group, связанные с составом группы |
| Квесты | Синхронизация мира и журнала через скрипты | Серверные квесты, Quest Studio, локализация, персональные квестовые предметы |
| Прокачка | Обычная система Morrowind либо внешние скрипты | Нативная серверная XP-система и опциональная потеря XP после смерти |
| Создание персонажа | Поток TES3MP/OpenMW 0.47 | Современные этапы, полный preview и безопасный multiplayer review/finalize |
| Интерфейс | Стандартные окна OpenMW/TES3MP | Quick Loot, новый инвентарь, панель цели, боевые полоски, меню игрока |
| AI NPC | Известные ограничения sync/authority | Multi-target combat sync, стабильный authority, тактика, двери, возврат домой |
| Графика | Рендер OpenMW 0.47 | HDR/bloom/SMAA, PBR, вода, occlusion culling, опциональное clustered lighting |
| Администрирование | Настройка CoreScripts и внешние инструменты | Управление сервером из лаунчера, hot reload, manifests, дополнительные проверки |
| Позиция после рестарта | Штатное сохранение | Постоянный кэш безопасной позиции и защита от падения сквозь мир |
| Платформы workflow | Официальные пакеты 0.8.1 | Windows x64, Linux x64/Steam Deck, экспериментальная macOS ARM64 |

## Что осталось знакомым

- Основные исполняемые файлы называются `tes3mp`, `tes3mp-server` и `tes3mp-browser`.
- Сохраняется Lua-модель серверных скриптов TES3MP и большая часть её API.
- Скрипты TES3MP часто можно портировать, но нужно проверить новые API, пакеты, группы, локализацию и server-authoritative системы.
- Источником игрового контента остаются файлы Morrowind. Состав и порядок плагинов у клиентов должен совпадать с требованиями сервера.
