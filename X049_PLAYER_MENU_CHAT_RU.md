# ArenaMP X049 — интерактивный чат / меню игрока

Основа: загруженный пользователем X048 `ArenaMP_X048_QUEST_CHAT_PLACEMENT_QUICKLOOT_CUMULATIVE(1).zip`.

## Что изменено

### 1. При открытии ввода появляется мышь и полноценная панель

Клавиша чата (`Y` по умолчанию) больше не показывает только строку ввода поверх HUD.

При активации:
- `GUIChat` переключает `InputManager` в mouse/UI mode;
- появляется рамочная тёмная панель на основе `MW_Box`;
- история, строка ввода и кнопки становятся полностью непрозрачными;
- пассивный HUD-чат после закрытия панели продолжает использовать старые режимы F2: visible / 30% / 60% / autohide / hidden;
- `Esc` и кнопка **«В игру»** закрывают панель.

### 2. Окно можно перетаскивать, позиция сохраняется

Верхняя полоса окна является drag handle.

После перемещения сохраняются в `[Chat]`:
- `x` / `y`;
- `w` / `h`;
- `panel layout version`.

Запись на диск debounced: во время движения `settings.cfg` не переписывается на каждый пиксель, сохранение происходит после небольшой паузы или при закрытии панели.

При смене разрешения окно больше не сбрасывается в старый `setCoord(10, 40, width-10, height/2)`, а только удерживается в границах нового viewport.

### 3. Три независимых выбора отправки сообщения

Панель чата имеет три группы кнопок.

**Режим:**
- `OOC` — обычное общение;
- `RP` — roleplay-маркер `[RP]`.

**Канал:**
- **Простой** — сохраняет историческое поведение сервера;
- **Локальный** — только игрокам в той же cell и в радиусе `config.localChatRadius`;
- **Глобальный** — всем игрокам, с явным `[Global]`.

**Стиль:**
- **Текст** — `Имя: сообщение`;
- `/me` — `* Имя действие`;
- `/do` — `* описание ((Имя))`.

Простой + OOC + Текст отправляется старым raw ChatMessage без обёртки. Любая специальная комбинация кодируется внутри того же сетевого ChatMessage как внутренняя `/ampchat ...`, которую X049 разбирает на сервере. Новый packet ID не вводился.

Если игрок сам вводит строку, начинающуюся с `/`, селекторы не вмешиваются: `/help`, административные и модовые команды остаются совместимыми.

### 4. Поведение RP по умолчанию

Если канал оставлен **Простой**:
- обычный OOC-текст остаётся глобальным, как в старом TES3MP/ArenaMP;
- RP, `/me` и `/do` автоматически считаются локальными;
- при необходимости RP можно вручную переключить на **Глобальный**.

Локальный радиус по умолчанию:

```lua
config.localChatRadius = 5000
```

Дополнительно требуется совпадение `tes3mp.GetCell()`; игроки из другой interior/exterior cell сообщение не получают.

### 5. После отправки: вернуться в игру или остаться

Добавлена сохраняемая toggle-кнопка **«После отправки остаться»**.

- выключена — Enter/«Отправить» отправляет текст и возвращает управление игре;
- включена — сообщение отправляется, поле очищается, меню и мышь остаются активны, можно сразу писать следующее сообщение.

Настройка хранится как `stay after send` в `[Chat]`.

### 6. Каркас будущего меню игрока

Вместо отдельного одноразового окна чат теперь является первой вкладкой общего меню:
- **Чат** — полностью рабочая вкладка X049;
- **Группа** — готовая UI-страница-заглушка под invite/leader/members/group chat/ready/shared markers;
- **Дом** — готовая UI-страница-заглушка под access list/guests/doors/locks/container permissions.

То есть следующий сетевой этап можно добавлять внутрь существующего Player Menu без очередной замены архитектуры чата.

### 7. Шрифт и эмодзи

Russo One больше не используется чатом и удалён из списка chat resources. Базовый чат переключён на уже имеющийся в OpenMW `DejaVuLGCSansMono` и получил настройку:

```ini
font = DejaVuLGCSansMono
```

Также добавлена раскрываемая кнопка **«Эмодзи»** с шестью Unicode-символами быстрого ввода.

Важно: это первая совместимая ступень, а не полноценный современный цветной emoji renderer. DejaVu LGC — свободный Latin/Greek/Cyrillic subset и не покрывает весь современный emoji Unicode. Для полного набора (например Noto Emoji/аналог) в этой ветке нужно отдельно добавить зарегистрированный MyGUI/OpenMW font resource либо emoji-atlas fallback. В X049 намеренно не добавляется отсутствующий TTF, чтобы сборка не зависела от несуществующего ресурса.

## Проверка в игре

1. Запустить клиент/сервер X049 и войти персонажем.
2. Нажать `Y`: должна появиться мышь и рамочная панель Player Menu.
3. Перетащить панель за верхнюю свободную область, закрыть игру, запустить снова — координаты должны сохраниться.
4. Проверить вкладки Чат / Группа / Дом и кнопку «В игру».
5. Обычный + OOC + Текст: поведение как у старого глобального чата.
6. Локальный + Текст: второй игрок в той же cell и ближе 5000 units видит сообщение; дальний/другая cell — нет.
7. RP + Простой: сообщение локальное и имеет `[RP]`.
8. Выбрать `/me`, затем `/do` и проверить форматирование.
9. Выбрать Глобальный + RP — сообщение видят все.
10. Ввести `/help` при любых выбранных кнопках — команда должна уйти в старый `commandHandler`, а не в `/ampchat`.
11. Включить «После отправки остаться»: после Enter окно остаётся активным и фокус возвращается в пустое поле.
12. Выключить toggle: после Enter управление возвращается игре.
13. Проверить `F2`: после закрытия интерактивной панели HUD-чат продолжает менять прозрачность/автоскрытие как в X048.
