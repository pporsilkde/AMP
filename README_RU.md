# ArenaMP

[English](README.md) · **Русский**

ArenaMP — экспериментальный мультиплеерный движок для *The Elder Scrolls III: Morrowind*. Проект продолжает кодовую базу TES3MP 0.8.1, поставляется со своим серверным ядром и объединяет крупные доработки интерфейса, геймплея, рендера, AI и администрирования.

> Нужна легальная копия *Morrowind*. Ресурсы Bethesda в проект не входят.

## Версия проекта

| Компонент | Значение |
|---|---|
| Снимок исходников | Y012 |
| Основа движка | OpenMW 0.47.0 |
| Мультиплеерная основа | TES3MP 0.8.1 |
| Сетевой протокол ArenaMP | 806 |
| Лицензия | GPLv3 с дополнительными условиями из [LICENSE](LICENSE) |

ArenaMP — самостоятельный форк, а не официальный релиз OpenMW или TES3MP. Номер протокола и структура пакетов отличаются от обычного TES3MP. Клиент и сервер должны быть собраны из одной версии ArenaMP.

## Основные возможности

- клиент, выделенный сервер, браузер серверов, лаунчер и встроенные CoreScripts;
- английский и русский интерфейс, локализация серверных сообщений под язык клиента;
- меню игрока с чатом, группами, списком игроков, цветами имён и цветными emoji;
- серверные группы, friendly fire, разделение XP в одной ячейке и опциональная синхронизация журнала/топиков;
- серверные квесты, внутриигровая Quest Studio и персональные квестовые предметы;
- современное создание персонажа, Quick Loot, улучшенный инвентарь, информация о цели и боевые полоски;
- нативная XP-прокачка, требования экипировки, Refined Alchemy, нанесение ядов и серверные правила геймплея;
- синхронизированный тактический AI, преследование через двери, восстановление authority и возврат NPC домой;
- HDR, bloom, SMAA, расширенный PBR, новая вода, динамические тени, исправления травы и CPU occlusion culling;
- опциональное кластерное освещение Project Magnus для настольного OpenGL 4.3;
- сборки Windows x64, Linux x64/Steam Deck и экспериментальная macOS ARM64.

Полный обзор: [возможности](docs/FEATURES.md) и [отличия от TES3MP](docs/TES3MP_DIFFERENCES_RU.md).

## Быстрый старт

### Игра

1. Скачайте пакет для своей платформы в разделе [Releases](https://github.com/MrZer0x0/TES3MP/releases) либо соберите проект.
2. Запустите `openmw-launcher` и укажите легальную установку Morrowind.
3. Настройте тот же набор и порядок плагинов, который использует сервер.
4. Запустите `tes3mp`, выберите сервер той же версии ArenaMP и войдите.

Короткое нажатие клавиши чата открывает быстрый ввод, удержание — полное меню игрока. В стандартной подсказке сервера используется `Y`.

### Свой сервер

Релизный пакет содержит `tes3mp-server` и те же серверные скрипты, что лежат в репозитории. Настройте сервер во вкладке лаунчера или в `server/scripts/config.lua`, затем запустите `tes3mp-server`.

Перед публичным запуском прочитайте [настройки механик](server/ARENAMP_CONFIG.md), [README сервера](server/README.md) и [заметки по безопасности](server/COREARENAMP_SECURITY.md).

### Сборка

Эталонный процесс релизной сборки описан в [.github/workflows/release-builds.yml](.github/workflows/release-builds.yml). Инструкции: [на русском](docs/BUILDING_RU.md) и [на английском](docs/BUILDING.md).

```bash
git clone --recurse-submodules https://github.com/MrZer0x0/TES3MP.git
cd TES3MP
bash CI/ensure-bundled-deps.sh
```

## Текущий статус

ArenaMP Y012 — рабочий снимок разработки, а не стабильный семантический релиз. Тактический AI, кластерное освещение, ragdoll и часть продвинутых режимов рендера остаются экспериментальными. Перед обновлением публичного сервера сделайте резервную копию и проведите тест с несколькими клиентами.

Код Android/ng-gl4es присутствует, но Android не собирается текущим релизным workflow и пока считается неподдерживаемой целью разработки.

### Y012 — вода / XP HUD / штрафы
- Shader water больше не возвращает старые particle-кольца, когда shader ripples выключены.
- XP-карточки без иконки и локализованы; плюс/минус/neutral оформлены зелёным/красным/чёрным.
- Смерть рассчитывается сервером: весь XP текущего уровня обнуляется, но уровень, Skill Points и навыки сохраняются. При ровно 0 XP сервер добавляет `level × 5 сек` к respawn time.
- Тюрьма обнуляет текущий XP и при XP Leveling не меняет случайные навыки. Сетевой протокол остаётся 806.

### Y011 — единые HUD-уведомления
Правая лента теперь использует одну равномерную полупрозрачную подложку вместо трёх полос затемнения. Получение XP и игровые XP-уведомления выводятся в эту же ленту; одинаковые быстрые награды суммируются. Предупреждения XP, вызванные из открытого GUI, сохраняют MessageBox. Вводимый текст ArenaMP-чата увеличен до 14 px и сделан белым, цвета истории чата не меняются.

### Y010 — оформление HUD-ленты
Карточки теперь прижаты к правому краю с отступом 2 px, отображаются без рамки на мягкой полупрозрачной подложке и показывают общий запас после подбора в формате `+5 (10)`.
