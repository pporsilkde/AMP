# EncoreMP 0.93 companion content

[Русское примечание](#русский) is below.

This directory contains optional ESP files supplied with the ArenaMP source snapshot. They are not required to compile or run the engine.

## Files

| File | Purpose |
|---|---|
| `EncoreMPV093.ESP` | Main companion plugin |
| `EncoreMPV093newcontent.ESP` | Optional race, birthsign, script, and content changes |
| `EncoreMPV093Spells1Base.ESP` | Spell package for the base game |
| `EncoreMPV093Spells2TRcore.ESP` | Spell package for base game + Tamriel Rebuilt core |
| `EncoreMPV093Spells3TRall.ESP` | Extended Tamriel Rebuilt spell package |

Use only one `EncoreMPV093Spells*` file. Every client and the server must use the same plugin list and order.

Detailed source notes are retained under `docs/`. Some historical notes identify the engine/content series as 0.9.2 while the included companion filenames are 0.93; the original wording is preserved for provenance.

## Русский

В каталоге находятся необязательные ESP из исходного билда ArenaMP. Для компиляции и запуска движка они не нужны.

Используйте только один файл `EncoreMPV093Spells*`. Состав и порядок плагинов должен быть одинаковым на сервере и у всех клиентов. Подробные исходные описания сохранены в `docs/`; различие между обозначениями 0.9.2 в старом changelog и 0.93 в именах приложенных ESP сохранено намеренно как часть истории файлов.
